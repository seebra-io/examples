# Seebra examples

The example dashboards of [Seebra](https://www.seebra.io), each a board kept as files in `examples/<id>/`: its code in `queries/`, `transforms/` and `graphs/`, its data in `data/`, its state in `.seebra/`.

**This repository is the examples' source.** What is on `main` is built into what Seebra opens (each board back into its dashboard spec and data) and published on Seebra's CDN when Seebra's build runs: after each update of the examples from Seebra's own repository, and by hand for a change merged here. Opening an example reads those built files: no git in the browser.

- **Open** one: `https://www.seebra.io/?example=<id>`, or its page in Explore, `https://www.seebra.io/explore/example-<id>`.
- **Edit with history:** `https://www.seebra.io/?board=git:https://github.com/seebra-io/examples#examples/<id>` clones this repository into the browser and shows the board with its commits; Edit in this clone, Commit… and Push send a change back.
- **Add one:** Submit to Explore in Seebra opens a pull request with the board's folder, its README and its `example.json`. By hand: a board folder in `examples/<id>/` (Save to folder… in Seebra writes one) and an `example.json` next to it (title, summary, description, categories, tags, apis: its Explore card). The build reads a folder's `example.json`, else its entry in `index.json`.

`index.json` lists them. The first version was generated by `frontend/scripts/examples-to-git.mjs` in Seebra's repository.
