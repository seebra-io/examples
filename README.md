# Seebra examples

The examples bundled with [Seebra](https://www.seebra.io), each a board kept as files in `examples/<id>/`: its code in `queries/`, `transforms/` and `graphs/`, its data in `data/`, its state in `.seebra/`.
Open one with `https://www.seebra.io/?board=git:https://github.com/seebra-io/examples#examples/<id>`; Seebra clones this repository into the browser and shows the board with its history.

Generated by `frontend/scripts/examples-to-git.mjs` in Seebra's repository. `index.json` lists them for Explore.
