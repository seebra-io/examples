# Vegard's law and lattice matching for epitaxy

III-V binaries and ordered (In,Ga)As and (Al,Ga)As cells (Alexandria, PBE) with measured cells (COD). Idea: an alloy's lattice constant is linear in composition (Vegard), its gap bows; solving for InP gives In0.53Ga0.47As with measured cells (0.47 with PBE). Caveats: PBE lattice constants 1–2% large and gaps far too small; ordered, not random, alloys.

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
- Data results aren't kept, except what `data/` holds: the rest comes back when the board runs.
- Generated by `frontend/scripts/examples-to-git.mjs` from the bundled example. Change the example in Seebra's repository and run the script again, or edit the board in Seebra (Open from git…, Edit in this clone, Commit…, Push).
