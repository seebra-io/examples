# The solar cycle, found by a periodogram

The monthly sunspot number since 1749 (SILSO v2 via NOAA SWPC). Signal idea: a periodogram computed in SQL finds the 11-year Schwabe cycle; cycle minima from a windowed minimum give 25 cycles of 9–13.6 years; flipping every other cycle's sign moves the peak to 22 years, the magnetic Hale cycle. Caveats: sparse early data; the flip assumes strict alternation.
