# Crypto markets

CoinGecko's 20 largest coins by market cap: Polars turns the answer into rows and the 7-day hourly price sparkline into log returns, then a chart shows the day's moves, each coin's volatility against its week, and the correlation matrix of hourly returns (most coins move with Bitcoin). Prices are in US$; a week of hours is a small sample.

**Open it in Seebra:** [as a board from git](https://www.seebra.io/?board=git%3Ahttps%3A%2F%2Fgithub.com%2Fseebra-io%2Fexamples%23examples%2Fcrypto-markets) (read only, with this folder's history) · [from Explore](https://www.seebra.io/?example=crypto-markets)

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
- Data results aren't kept, except what `data/` holds: the rest comes back when the board runs.
- Generated by `frontend/scripts/examples-to-git.mjs` from the bundled example. Change the example in Seebra's repository and run the script again, or edit the board in Seebra (Open from git…, Edit in this clone, Commit…, Push).
