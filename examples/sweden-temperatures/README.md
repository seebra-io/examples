# Temperature across Sweden now

SMHI's latest hourly air temperature from every reporting weather station in Sweden, on a map from Smygehuk to Abisko, with the warmest and coldest stations. Statistics: a straight-line trend of temperature against latitude, with a 95% band for the line (and a wider one for a single station), so you can see how much colder each degree north is this hour and how sure that slope is. One hour is a snapshot; height and coast also matter. Quality G is checked, Y is suspect or not yet checked.

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
