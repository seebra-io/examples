# US drug recalls

The 100 most recently reported drug recalls in openFDA's enforcement reports: which firms, how serious (Class I: may cause serious harm or death; II: temporary or reversible harm; III: unlikely to harm) and why. A count needs an exposure: all recalls per route of administration are divided by the products listed per route in the NDC directory, with a 95% Poisson interval, so a route with many products doesn't look riskier just for being big. A firm's count has no such denominator here. Reports are weekly; openFDA data are not for medical decisions.

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
- Data results aren't kept, except what `data/` holds: the rest comes back when the board runs.
- Generated by `frontend/scripts/examples-to-git.mjs` from the bundled example. Change the example in Seebra's repository and run the script again, or edit the board in Seebra (Open from git…, Edit in this clone, Commit…, Push).
