# Kubernetes warning events

Your cluster's warning events over the last hour, by reason and object, and the ones that keep recurring. Statistics: events as a Poisson process, with a dispersion index and burst minutes (Bonferroni over the window). Needs signing in and your cluster connected through your organization's gateway.

**Open it in Seebra:** [as a board from git](https://www.seebra.io/?board=git%3Ahttps%3A%2F%2Fgithub.com%2Fseebra-io%2Fexamples%23examples%2Fk8s-events) (read only, with this folder's history) · [from Explore](https://www.seebra.io/?example=k8s-events)

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
- Data results aren't kept, except what `data/` holds: the rest comes back when the board runs.
- Generated by `frontend/scripts/examples-to-git.mjs` from the bundled example. Change the example in Seebra's repository and run the script again, or edit the board in Seebra (Open from git…, Edit in this clone, Commit…, Push).
