# NASA in 3D: the model catalog

Every 3D model science.nasa.gov publishes, read live from its WordPress media API: 358 glTF models and 7 STL files for printing, by collection (NASA 3D Resources, the solar system, Mars, missions), size and month added. Hover a dot for the model, click it for the file; Hubble opens in 3D below, and any model in the table opens the same way (a query of its url, viewModel in a graph). Awareness: the dates are when a file reached the rebuilt science.nasa.gov (the old NASA 3D Resources moved over in bulk in spring 2025), not when it was made; sizes run from kilobytes to almost 100 MB, and Seebra reads files up to 25 MB. Next: Mars in 3D, and Perseverance: who built what.

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
- Data results aren't kept, except what `data/` holds: the rest comes back when the board runs.
- Generated by `frontend/scripts/examples-to-git.mjs` from the bundled example. Change the example in Seebra's repository and run the script again, or edit the board in Seebra (Open from git…, Edit in this clone, Commit…, Push).
