# The euro against seven currencies

European Central Bank reference rates (via Frankfurter) since January 2025: each currency indexed to 100 at the start, so you can see which gained or lost against the euro, with the change, low and high per currency. Statistics: daily log returns (the change in the log of the rate, which add up over days) and their standard deviation, the volatility, per month and annualised (× √252), so a calm currency and a jumpy one can be told apart even when they end at the same place. ECB publishes once per working day around 16:00 CET; a month has only about 21 returns.

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
- Data results aren't kept, except what `data/` holds: the rest comes back when the board runs.
- Generated by `frontend/scripts/examples-to-git.mjs` from the bundled example. Change the example in Seebra's repository and run the script again, or edit the board in Seebra (Open from git…, Edit in this clone, Commit…, Push).
