# Upcoming rocket launches

The next 30 orbital launches from The Space Devs' Launch Library 2: when (and how sure the date is), who, which rocket and pad, and what they carry (hover a launch for its record, click for its Launch Library page). Statistics: Poisson waiting times. If launches came at random at a steady rate, the gaps between them would be exponential, a straight line on a log axis; the last 100 launches are compared with that model, with the rate per day and the chance of a day without a launch. The ratio sd / mean of the gaps is 1 for a Poisson process (below: more regular, above: clustered by campaigns, ranges and weather); the 100 launches give only 99 gaps, and they are past launches because upcoming dates known only to the month pile up at its end. The free API allows 15 requests an hour (this dashboard makes two).

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).

- Generated by `frontend/scripts/examples-to-git.mjs` from the bundled example. Change the example in Seebra's repository and run the script again, or edit the board in Seebra (Open from git…, Edit in this clone, Commit…, Push).
