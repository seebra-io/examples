# Public holidays this week

Nager.Date's public holidays in every country it covers for the coming seven days, joined with country names: what is celebrated where, whether nationwide or regional. Statistics: Poisson counts. If holidays fell independently at a steady rate, the count per day would be Poisson around the week's mean; the dispersion index (variance over mean, 1 for Poisson) and P(at least this many) per day show whether they cluster instead. Caveat: one week is seven numbers, Nager.Date lists about 200 countries but how fully it records regional holidays varies, and a day with no holiday counts as zero.
