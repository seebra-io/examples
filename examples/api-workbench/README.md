# REST API workbench

Developing against a REST API: call endpoints, join their answers and check the shape of the data: which fields every record has, which users and posts match in a full join, and the distribution of body lengths with its quantiles before averaging it. Uses JSONPlaceholder as a stand-in (a fixture: every user has exactly 10 posts); point the datasource at http://localhost:<port> and Seebra calls your local API straight from the browser.

**Open it in Seebra:** [as a board from git](https://www.seebra.io/?board=git%3Ahttps%3A%2F%2Fgithub.com%2Fseebra-io%2Fexamples%23examples%2Fapi-workbench) (read only, with this folder's history) · [from Explore](https://www.seebra.io/?example=api-workbench)

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
- Data results aren't kept, except what `data/` holds: the rest comes back when the board runs.
- Generated by `frontend/scripts/examples-to-git.mjs` from the bundled example. Change the example in Seebra's repository and run the script again, or edit the board in Seebra (Open from git…, Edit in this clone, Commit…, Push).
