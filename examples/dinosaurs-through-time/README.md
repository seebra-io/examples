# Dinosaurs through time

Every non-bird dinosaur genus in the Paleobiology Database: when each lived (first to last find), how many genera lived in each age of the Mesozoic and how fast they appeared and vanished, and where their fossils are dug up today against where those places were when the animals lived. Mind the third panel: the diversity curve rises and falls with how many fossils each age has. Next: The big five extinctions.

**Open it in Seebra:** [as a board from git](https://www.seebra.io/?board=git%3Ahttps%3A%2F%2Fgithub.com%2Fseebra-io%2Fexamples%23examples%2Fdinosaurs-through-time) (read only, with this folder's history)

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
- Data results aren't kept, except what `data/` holds: the rest comes back when the board runs.
- Generated by `frontend/scripts/examples-to-git.mjs` from the bundled example. Change the example in Seebra's repository and run the script again, or edit the board in Seebra (Open from git…, Edit in this clone, Commit…, Push).
