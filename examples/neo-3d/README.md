# Asteroids in 3D

The asteroids passing Earth in the coming week (NASA NeoWs), around Earth in 3D: each at its real miss distance on a log scale with the Moon's orbit for reference, sized by estimated diameter, red when potentially hazardous (hover for the record, click for its JPL page). NeoWs gives no approach direction, so directions are illustrative. Statistics: the empirical cumulative distribution (ECDF) of miss distance on a log axis, so you can read off the median and the share within the Moon's distance, 10× and 100× it. A week is a few dozen objects, and the feed only lists approaches within about 0.5 au (195 lunar distances), so the curve reaching 100% there is the list's cut-off. DEMO_KEY allows 30 requests an hour. With the coming month's flybys as estimated trajectories past Earth (JPL's close approaches and orbits, two-body Kepler motion), checked against JPL's own distances.

## This folder

- The board's folder is a git working tree (.seebra format 2): code in `queries/`, `transforms/` and `graphs/`, named after the steps; data kept with the board in `data/`; the board's state in `.seebra/` (one JSON per step, `seebra.json` naming the board).
